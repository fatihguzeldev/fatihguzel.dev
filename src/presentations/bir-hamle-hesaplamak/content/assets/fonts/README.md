# Bricolage Grotesque

Variable TrueType font by Mathieu Triay, distributed under the SIL Open Font License 1.1. See `OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque

Original project: https://github.com/ateliertriay/bricolage

The unmodified font includes Turkish glyphs and proportional and tabular numerals. Its weight axis covers 200–800; the presentation uses weights from 450 through 800.
