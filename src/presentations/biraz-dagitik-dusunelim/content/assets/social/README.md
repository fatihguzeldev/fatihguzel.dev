# social marks

Local, self-contained SVG assets for the speaker introduction. The brand paths and square `viewBox` values are unchanged; their fill is set to the presentation ink (`#1e2329`) and accessibility titles use lowercase. No external fonts, scripts, styles, images, or resources are required.

## source

The three brand marks come from [Simple Icons 11.0.0](https://github.com/simple-icons/simple-icons/tree/11.0.0), pinned to commit `afc1b5674f1f83b6f454d475152bfad8edc916ce`. Twitter deliberately uses the bird mark requested for this presentation.
